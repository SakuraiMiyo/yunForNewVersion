添加你的照片

取景要求（导入时逐项自动检查）

      

        
位置
脸在画面中部：上、下各留 ≥ 1/5 画面高，左右各留 ≥ 1/10 画面宽，脸框完整。

        
大小
脸宽占画面宽 40%–65%，约一臂距离的半身自拍。

        
姿态
正脸直视：不侧脸、不仰俯、不歪头（倾角 ≤ 15°）。

        
质量
清晰原片、光线充足；逆光 / 模糊 / 大俯角过不了。未过原因显示在缩略图下方。

      

      
照片仅存本机 data/face_library/；开了人脸而未激活照片时，
        控制台在准备与确认时会红字提醒，执行在开始前被拒。
